# Knowledge (social-media summaries, unverified)

Ideas from social media and talks. Not verified in this repo. Treat as hypotheses.

- Design loop, not prompt. Iterate on the spec and tests, not on the prompt.
- Maker/checker with verdicts: ship / fix-first / rethink. A checker agent that cannot say rethink is decoration.
- Missing token usage is "unknown", never zero. Zero hides cost.
- Agent drives the running app. Hot reload plus real UI checks beat static review.
- "The AI says it works" is not evidence. Run the check and cite the output.
