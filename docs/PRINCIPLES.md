# Principles

- Software fundamentals matter more than ever (Matt Pocock). Code is cheap to write and expensive to own. Bad code costs most when agents write it fast.
- Entropy: every change must consider the whole system, not just the diff.
- Align on a shared design concept first. Grill before you build.
- Keep the ubiquitous language (CONTEXT.md). Same words in code, tests, and talk.
- TDD in small steps. Feedback rate is the speed limit. Agents outrun their headlights.
- Deep modules with simple interfaces. Test at the boundary.
- Design the interface yourself; delegate the implementation (gray boxes).
- Name module changes and interfaces inside every spec.
- Invest in design every day, not in a rewrite.
- Ousterhout: deep modules; strategic over tactical programming.
- Pragmatic Programmer: tracer bullets, DRY, fix broken windows.
- Brooks: conceptual integrity; no silver bullet.
- DDD: ubiquitous language; bounded context.
